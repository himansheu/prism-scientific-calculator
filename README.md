# PRISM

**A different perspective on calculation.**

A retro-modern scientific calculator built with HTML, CSS, and vanilla JavaScript.

**[↗ Live Demo](https://prism-scientific-calculator.vercel.app/)**

### Features
- Scientific & trigonometric functions
- Custom expression parser — no `eval()`
- Live calculation preview
- Calculation history
- Keyboard shortcuts
- DEG / RAD modes
- Responsive interface

### Built With
`HTML` · `CSS` · `JavaScript`
